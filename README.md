# Student Profile

This is my Student Profile application built using Flutter and Dart with `StatelessWidget`.

The application displays my personal and academic information, including my full name, course, student number, year level, section, and school email. It also includes an About Me section and my hobbies and interests.

The profile uses a circular avatar with my initials, a card for my student details, and chips to display my hobbies. Since the information is static, the application uses `StatelessWidget` without needing to manage changing data.
